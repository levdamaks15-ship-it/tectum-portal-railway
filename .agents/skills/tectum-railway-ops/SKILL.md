# Регламент эксплуатации и деплоя на Railway

## 1. Среда выполнения и сборка Nixpacks
- **Сборка Nixpacks / Mise:**
  - Конфигурация Python и зависимостей в `.mise.toml` или переменных Railway.
  - **Строгая кодировка UTF-8 без BOM:** Все файлы проекта (`.py`, `.html`, `.js`, `.css`, `.json`, `.md`) обязаны сохраняться в UTF-8 без BOM. Файлы в CP1251 приводят к фатальному падению сборщика Nixpacks (`stream did not contain valid UTF-8`).
- **Procfile:**
  - Запуск через `web: uvicorn main:app --host 0.0.0.0 --port $PORT`.
- **Чистота корня репозитория:**
  - Запрещено коммитить отладочные скрипты в корень. Все временные утилиты размещаются в `scratch/` (в `.gitignore`).

## 2. Постоянное хранилище (Railway Volume) и WebP
- **Постоянный том для загрузок:**
  - Все загружаемые файлы (фото дефектов, сканы документов, вложения задач) сохраняются в постоянный подключенный том (`/uploads` или `RAILWAY_VOLUME_MOUNT_PATH`).
- **Автоматическая компрессия фото в WebP:**
  - Фотографии сжимаются в формат WebP на стороне сервера для экономии места на диске и ускорения открытия на смартфонах мастеров в цеху.

## 3. Защита при деплое и перезапуске (Deployment Guard)
- **Проверка версии сервера (`/api/system/version`):**
  - Клиент периодически опрашивает статус версии. Все страницы отдаются с `Cache-Control: no-cache, no-store, must-revalidate`.
  - При перезапуске контейнеров (статусы 502/503/504) выводится полноэкранный неблокируемый оверлей (`z-index: 99999`) с понятным сообщением об обновлении.
- **Защита активных форм мастера (Safe Auto-Update):**
  - Категорически запрещен принудительный релоад страницы при наличии активного несохраненного ввода или открытых модальных окон (рапорты смен, чек-листы, задачи).
  - Данные активной формы автоматически сохраняются в `localStorage`, а обновление откладывается до закрытия окна.
  - Сброс мобильного кэша скриптов выполняется с параметром версии `?v=<commit_sha>`.

## 4. Сетевая устойчивость в цехах (Network Resilience Guard)
- **Таймауты и автоповторы:**
  - В условиях слабого цехового Wi-Fi/LTE все вызовы к `/api/*` снабжаются жестким таймаутом (12 сек через `AbortController`).
  - Кратковременные шлюзовые сбои (502/503) автоматически сглаживаются механизмом повтора (до 2 ретраев с паузой).
- **Информативные уведомления:**
  - Запрещены резкие блокирующие `alert()`. Ошибки транслируются через понятные Toast-уведомления на русском языке.

## 5. Переменные окружения хостинга (Railway / Render)
При разработке или изменении интеграций, требующих внешних ключей (`GOOGLE_SPREADSHEET_ID`, `GOOGLE_CREDENTIALS_JSON`, `M365_CLIENT_ID`, `M365_TENANT_ID`, `M365_CLIENT_SECRET`), агент **обязан напомнить пользователю** добавить эти переменные в панель управления Railway/Render. Не предполагать, что локальный `.env` автоматически синхронизируется с облаком.
